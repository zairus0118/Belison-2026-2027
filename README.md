# Maison Aura – Perfume Shop (React + Vite)

## Run
1. Install Node.js (https://nodejs.org)
2. Open this folder in VS Code terminal
3. `npm install`
4. `npm run dev`
5. Open the link shown (http://localhost:5173)

## Connect to Django later
Edit `src/api.js`: set `USE_API = true` and check the endpoint paths against your shop/urls.py.
